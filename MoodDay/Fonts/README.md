# Bundled fonts

Anonymous Pro Bold and Caveat are bundled from https://github.com/google/fonts with their accompanying SIL Open Font Licenses.

The step label uses AnonymousPro-Bold; the page title uses Caveat-Regular. Happy requests Figma Hand when installed in the browser, falling back to Caveat. The native app explicitly uses Caveat for Happy until a usable Figma Hand font file is supplied. Figma Hand was not present in the local font folders, and its official page provided no standalone download: https://www.figma.com/fonts/figma-hand/.

The body description is 14px in the browser and 14pt at default Dynamic Type size on iOS.
